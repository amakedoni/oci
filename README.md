# Лабораторная работа 2

**Вариант 4. Управление процессами и обмен данными через каналы.**

Македонский Александр Сергеевич, группа М8О-210БВ-25.

Программа написана на C11 с использованием POSIX API для Linux. Родитель передаёт строки чисел через канал дочерней программе. Потомок последовательно делит первое число на остальные и записывает результат в файл. Нулевой делитель проверяется в потомке и завершает оба процесса.

## Сборка и запуск

Нужны C-компилятор и Make. Команды выполняются из корня репозитория:

```sh
make -C src
./src/build/parent
```

Первая строка ввода — имя выходного файла. Существующий файл перезаписывается. Затем вводятся строки чисел с десятичной точкой. Для завершения ввода используется Ctrl-D.

```text
result.txt
100 2 5
7.5 2.5
-24 2 -3
```

Файл `result.txt` будет содержать числа `10`, `3` и `4`, каждое с новой строки. Пустые строки пропускаются; строки с некорректными числами отклоняются с диагностикой. Диагностика с PID выводится в stderr.

Готовые примеры:

```sh
./src/build/parent < src/examples/normal.in
cat src/build/results.txt
./src/build/parent < src/examples/zero.in
```

Во втором примере код завершения равен `2`, а в `src/build/zero-result.txt` остаётся только `6`: команда после нулевого делителя не выполняется.

## Проверки

Для тестов нужен Python 3 без дополнительных пакетов.

```sh
make -C src test
make -C src sanitize
```

Проверяются вычисления, ошибочный ввод, длинные строки, обрыв каналов, системные ошибки и завершение процессов. Логи сохранены в `report/logs/`. Проверки выполнены на macOS с Apple Clang; запуск в Linux и трассировка strace в этих логах не представлены.

## Демонстрация через strace

На Linux с установленным strace:

```sh
make -C src
strace -f -o src/build/trace.log ./src/build/parent < src/examples/zero.in
echo $?
cat src/build/zero-result.txt
```

Ожидаются код `2` и число `6` в выходном файле. `-f` включает наблюдение за потомком, `-o` сохраняет журнал. strace запускается снаружи программы; в исходниках показаны системные вызовы, которые он отслеживает.

| В журнале | Место в исходниках |
| --- | --- |
| `pipe` или `pipe2`, `fork` или `clone` | `src/parent.c`, строки 64–72 |
| `dup2`, `execve` | `src/parent.c`, строки 78–82 |
| `openat`, запись результата | `src/child.c`, строки 32 и 74 |
| Ответ `write(1, "Z", 1)` | `src/child.c`, строки 62 и 14; `src/common.c`, строка 33 |
| `wait4` | `src/common.c`, строка 126, вызов `waitpid` |

Имена библиотечных функций и вызовов ядра могут отличаться. Чтение строк реализовано по одному байту: это упрощает код, но увеличивает число `read` на длинных строках. Фактическая Linux-трасса в сохранённых логах отсутствует.

## Состав

- `src/parent.c` — создание потомка и обмен командами.
- `src/child.c` — обработка команд и запись результатов.
- `src/common.c`, `src/common.h` — каналы, чтение строк, сигналы и ожидание потомка.
- `src/division.c`, `src/division.h` — разбор чисел и деление.
- `src/Makefile`, `src/tests/`, `src/examples/` — сборка, тесты и примеры.
- [Отчёт PDF](report/report.pdf) и [редактируемый отчёт DOCX](report/report.docx).

Очистка файлов сборки: `make -C src clean`.
